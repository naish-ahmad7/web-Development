There are three ways to write CSS:

  1. Inline CSS - Inline CSS is written directly inside an HTML element using the <style> attribute.
  2. Internal CSS - Internal CSS is written inside the <style> tag in the <head> section of an HTML document.
  3. External CSS - External CSS is written in a separate .css file and linked to an HTML document using the <link> tag
